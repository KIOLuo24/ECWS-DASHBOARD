+# KIOwork
+
+一个可编辑的经营测算看板，用于模拟团队规模、岗位工资、产品套餐定价、销售提成、风险备用金、场地设备和自定义成本对年度利润分配的影响。
+
+## 功能
+
+- 按 5 年规划维护不同岗位的人数和月工资，自动汇总各年度工资成本。
+- 维护产品套餐价格、提成比例、风险备用金比例，并展示每单提成。
+- 维护办公室、域名、服务器等固定成本，也可以新增任意自定义成本。
+- 新增多个销售预测场景，输入各套餐销量后自动计算收入、工资成本、提成、固定成本、风险金、利润和利润率。
+- 按股东 50%、项目经理 10%、开发经理 10%、再投入开发资金 20%、日常运营耗损 5%、全公司奖金池 5% 自动拆分利润。
+
+## 本地运行
+
+```bash
+npm install
+npm start
+```
+
+## 测试
+
+```bash
+npm test
+```
